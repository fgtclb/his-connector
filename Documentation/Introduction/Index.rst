Introduction
============

What does it do?
================

The :guilabel:`HIS Connector` extension connects TYPO3 with HIS
(Hochschul-Informations-System) so that data maintained in the campus
management system can be used within a TYPO3 based website.

..  note::

    The extension is currently being built up. This chapter is extended along
    with the implemented features.
